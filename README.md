# LLM-мост для танка LAFVIN (LA033 / Mini Tank)

> Финальная конфигурация от 15.11.2026.
> Мозг: Qwen3.8-FN-IQ3-S-Basalt на LLM-сервере в LAN (OpenAI API, адрес в bridge.py).
> Запасной вариант: локальная Ollama (`LLM_BACKEND = "ollama"` в bridge.py).

Управление учебным танком через локальную LLM (Ollama) по Bluetooth.

```
Вы → Ollama (LLM на ПК) → bridge.py → Bluetooth HC-06 → Arduino → моторы/датчики
```

## 1. Прошивка Arduino

1. **Выньте модуль HC-06** из слота на расширительной плате
   (он сидит на тех же RX/TX, что и USB — с вставленным модулем скетч не зальётся).
2. Откройте `TankLLM/TankLLM.ino` в Arduino IDE, выберите плату
   *Arduino Uno*, нужный порт, залейте.
3. Отключите USB, вставьте HC-06 обратно, включите танк.

## 2. Сопряжение Bluetooth

- Спарите HC-06 с компьютером, пароль обычно `1234` (иногда `0000`).
- Узнайте порт:
  - **macOS**: `ls /dev/tty.*` — будет что-то вроде `/dev/tty.HC-06-DevB`
  - **Windows**: Диспетчер устройств → Порты (COM и LPT) → «Standard Serial over Bluetooth link»
  - **Linux**: `bluetoothctl` → `pair`, затем `sudo rfcomm bind 0 <MAC>` → `/dev/rfcomm0`
- Порт и остальные настройки задаются через переменные окружения (см. ниже).

## 2.1. Настройки через окружение

Все адреса, ключи и пины вынесены из кода. Скопируйте шаблон и заполните:

```bash
cp .env.example .env   # .env не коммитится (см. .gitignore)
```

Переменные: `TANK_BT_ADDR` (MAC модуля HC-06), `TANK_BT_PIN`,
`TANK_SERIAL_PORT`, `TANK_BAUD`, `TANK_LLM_BACKEND` (`openai`/`ollama`),
`TANK_MODEL`, `TANK_OPENAI_URL`, `TANK_OPENAI_KEY`, `TANK_OLLAMA_URL`.
Можно задавать и напрямую в окружении — `.env` лишь подхватывается,
если переменная не задана.

## 3. Ollama

```bash
# macOS / Linux
brew install ollama        # или https://ollama.com/download
ollama pull qwen2.5:7b-instruct
ollama serve               # если не запущен как служба
```

## 4. Запуск моста

```bash
pip install pyserial
python bridge.py
```

Если порт открылся и танк ответил приветствием `READY TankLLM v1.0` — можно писать
команды человеческим языком:

```
Вы > осмотрись и скажи, куда можно проехать
Вы > проедь вперёд пару секунд, потом развернись и вернись
Вы > если справа свободно — поверни направо, иначе налево
```

## Протокол команд танка

Мост шлёт текстовые строки, танк отвечает одной строкой:

| Команда | Ответ | Действие |
|---|---|---|
| `PING` | `PONG` | проверка связи |
| `FWD <ms>` / `BACK <ms>` | `OK` | езда вперёд/назад |
| `LEFT <ms>` / `RIGHT <ms>` | `OK` | разворот на месте |
| `STOP` | `OK` | стоп |
| `SPEED <0..255>` | `OK` | базовая скорость (PWM), обе стороны |
| `TRIM <лев> <прав>` | `OK` | раздельная скорость сторон (калибровка, до перезагрузки) |
| `SCAN` | `DIST:d1,d2,d3,d4,d5` | замер в 5 направлениях (см, 400 = свободно) |
| `STATUS` | `SPEED:n MAXDUR:n` | текущие настройки |

Проверить связь можно и без Python: в мониторе порта Arduino IDE (9600 бод,
«Новая строка (LF)») при подключённом HC-06 отправьте `PING`.

## Калибровка

Откалибровано 15.11.2026: `speedL=168`, `speedR=255` (пины 5/6 на этой плате
физически перепутаны относительно названий — сторона на пине 5 быстрее).
Точную подстройку можно делать на лету командой `TRIM <лев> <прав>` без перепрошивки;
чтобы закрепить — впишите значения в `speedL`/`speedR` в скетче и перепрошейте.

Голова с датчиком: `servoCenter=107` (заводские 90° смотрели вправо).
Подстройка без перепрошивки — команда `CENTER <5..175>`.

## Калибровка (общие советы)

Голова с датчиком: `servoCenter=107` (заводские 90° смотрели вправо).
Подстройка без перепрошивки — команда `CENTER <5..175>`.

- **Едет криво**: подберите `speedL` / `speedR` в начале скетча
  (у слабой стороны PWM больше).
- **Разворот не на 90°**: время разворота подбирается опытом; сообщите LLM
  фактическое (например: «разворот 600 мс ≈ 90°»), оно учтёт.
- **Серво «дрожит» у краёв**: сузьте углы в массиве `angles` в функции `scan()`.

## Защита

- Длительность любого движения ограничена 3000 мс на стороне Arduino
  (даже если LLM пришлёт 999999).
- После каждой команды движения моторы останавливаются автоматически.
- Мост дополнительно клампит `duration_ms` в диапазон 100–3000.

## Правила поведения LLM (системный промпт)

- Порог «тесно»: < 15 см впереди — не ехать; ≥ 15 см — можно
- Движение назад запрещено полностью (промпт + инструмент + код)
- Поиск проезда: повороты на месте ТОЛЬКО влево, шагами 250–300 мс (~30–40°),
  с осмотром после каждого поворота
- ИК-датчики спереди (A1/A2): аварийный автостоп в прошивке (STOPPED_IR)
  + инструмент check_ir для LLM
- Лимит: 40 шагов на команду, затем аварийный STOP

## Особенность HC-06 на macOS

Клоны HC-06 + macOS: данные по SPP идут только по «свежему» каналу, поэтому
`bridge.py` при каждом запуске автоматически делает переспаривание
(unpair → pair 1234 → connect, через blueutil). Это норма, не ошибка.
Признак живого линка — светодиод HC-06 горит ровно (не мигает).

## Если нет Bluetooth на ПК

Вариант запасной: подключить танк кабелем USB и указать его порт в
`SERIAL_PORT` (например `/dev/tty.usbserial-XXXX` или `COMx`) — мост заработает
точно так же, только танк будет на «поводке».
