### Почему сервер, а не Mac

- Короткий маршрут: Mac больше не участвует в управлении — только браузер.
- Bluetooth-адаптер сервера (Broadcom BCM20702A0) спарен с HC-06 один раз
  (`bluetoothctl pair` + `trust`), подключение запускается вручную кнопкой «Связь».
- На macOS клоны HC-06 требовали переспаривания при каждом запуске (blueutil);
  на Linux ручная кнопка запускает переспаривание через bluetoothctl.
- Транспорт выбирается автоматически: `platform.system() == "Darwin"` →
  blueutil + `/dev/cu.HC-06`, иначе → raw RFCOMM-сокет (класс `RFCOMMLink`,
  имитирует serial.Serial: write / readline / reset_input_buffer).

## Протокол WebSocket (клиент ↔ server.py)

**Клиент → сервер:**

| Сообщение | Действие |
|---|---|
| `{"type":"task","text":"..."}` | Запустить LLM-агент с заданием |
| `{"type":"agent_stop"}` | Остановить агента (флаг + STOP танку) |
| `{"type":"cmd","cmd":"FWD 500"}` | Ручная команда (белый список: FWD/BACK/LEFT/RIGHT/STOP/SCAN/IR) |
| `{"type":"map_reset"}` | Сбросить карту и одометрию |

**Сервер → клиент:**

| Сообщение | Содержимое |
|---|---|
| `{"type":"log","dir":"tx/rx/llm/sys","text","ts"}` | Строка журнала обмена |
| `{"type":"map","pose","trail","obstacles"}` | Поза робота, путь, точки препятствий |
| `{"type":"agent","state":"running/idle"}` | Состояние агента (блокирует кнопку) |
| `{"type":"link","state":"ok/fail"}` | Статус Bluetooth-связи |

## Ключевые решения

1. **Единственный владелец UART.** Все команды танку идут через `tank_cmd()` под
   `threading.Lock` — ручные кнопки и LLM-агент не могут «перебить» друг другу
   пакет в середине. Агент работает в отдельном потоке и тоже ходит через этот замок.

2. **Одометрия без энкодеров (dead reckoning).** Сервер сам считает позу:
   - `FWD/BACK <ms>` → сдвиг на `30 см/с × время` по текущему курсу
   - `LEFT/RIGHT <ms>` → поворот курса на `0.12° × мс`
   - `SCAN` → 5 точек препятствий на лучах −70°…+70° на измеренных дистанциях
   - `STOPPED_IR` → метка препятствия в ~10 см по курсу

   Точность ограничена (без энкодеров путь «плывёт»), для карты комнаты — достаточно.
   Константы `SPEED_CM_S` и `TURN_DEG_PER_MS` — калибровочные, в начале server.py.

3. **Переиспользование bridge.py.** Мост не дублируется: server.py импортирует
   готовый модуль (инструменты, промпт, chat()). WebTank — тонкий адаптер,
   подменяющий прямой serial-вызов на tank_cmd с логом и картой.

4. **Mock-режим.** `TANK_MOCK=1 python3 server.py` — разработка UI без железа:
   фиктивные ответы, имитация сканов случайными дистанциями.

5. **Клиент без сборки.** Один index.html: нативный WebSocket, карта на
   `<canvas>` с сеткой 50 см, камера следует за роботом.

## Эксплуатация на сервере


## Диагностика связи

При запуске и после обрыва автоматического подключения нет. Кнопка «Связь»
выполняет переспаривание и подключение; heartbeat только проверяет живой канал.
События связи, команды и ответы доступны в пульте и в journalctl. PIN скрывается.
